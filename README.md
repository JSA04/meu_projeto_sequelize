# Sistema de Usuários — Node.js + Sequelize + MySQL + Handlebars

## Descrição
Aplicação simples para gerenciar usuários e endereços (CRUD), construída com Node.js, Express, Sequelize (MySQL) e templates Handlebars. Interface responsiva e funcional.

## Funcionalidades
- Cadastrar, listar, editar e excluir usuários
- Adicionar e remover endereços vinculados a usuários
- Relacionamento 1:N (User -> Addresses)
- Layout responsivo com Handlebars e CSS custom

## Tecnologias
- Node.js, Express
- Sequelize ORM
- MySQL / mysql2
- express-handlebars
- Nodemon (dev)

## Pré-requisitos
- Node.js (v16+ recomendado)
- MySQL rodando localmente ou em servidor acessível
